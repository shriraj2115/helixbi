# HelixBI Issue Tracking Log

This file contains the mandatory issue tracking log. For every issue encountered, we document:
- **Issue**: Description of the issue
- **Root Cause**: Why the issue happened
- **Reproduction Steps**: Step-by-step guide to reproduce
- **Severity**: Low / Medium / High / Critical
- **Fix Applied**: Details of the fix
- **Prevention Strategy**: How we prevent this in the future
- **Chances of Regression**: Low / Medium / High (with explanation)
